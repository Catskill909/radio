# Custom Menu

The Custom Menu feature allows you to add a customizable floating menu to your public listen page. This hamburger-style menu appears in the bottom-right corner and provides quick access to important links and information.

## Accessing Custom Menu Settings

Navigate to **Settings** in the admin panel. The **Custom Menu** section appears between Site Branding and Station Identity.

## Menu Toggle

Use the **Show Menu** toggle to enable or disable the entire floating menu on your listen page. When disabled, the hamburger button won't appear for visitors.

## Adding Menu Items

Click **Add Menu Item** to create a new entry. You can have up to **8 menu items** maximum.

### Reordering Items

Drag items using the grip handle (⠿) on the left side to reorder them. The order determines how they appear when the menu opens.

## Configuring Each Item

### Icon
Enter a Font Awesome icon class (e.g., `fa-solid fa-info-circle`). Click the **Icons** link to browse the free icon collection on FontAwesome.com.

### Label
The tooltip text shown when users hover over the menu item. Maximum 30 characters.

### Action Type

Choose between two types:

- **URL**: Opens an external link in a new tab
- **Modal**: Displays a popup overlay with custom content

#### URL Items
Enter the full URL including `https://` (e.g., `https://example.com/about`).

#### Modal Items
- **Header**: The title shown at the top of the modal (max 50 characters)
- **Body**: The main content. Use Enter to create line breaks which will be preserved in the display (max 2000 characters)

## Default Items

When first enabled, five placeholder items are provided as examples:
- About Us (URL)
- Schedule (URL)
- Podcast (URL)
- Contact (Modal)
- About the Station (Modal)

You can edit or delete these to customize for your station.

## Saving Changes

Click **Save Menu Settings** to apply your changes. The floating menu on your listen page will update immediately.
